# C-digo-simulador-impuestos-
Aplicación web interactiva para calcular ISR estimado, analizar gastos mensuales y recibir recomendaciones básicas de ahorro e inversión.
# Mi Dinero Inteligente 💰

Aplicación web interactiva diseñada para ayudar a estudiantes, empleados, freelancers y emprendedores a comprender mejor sus finanzas personales.

## Características

✅ Cálculo estimado de ISR basado en ingresos mensuales

✅ Registro de gastos deducibles

✅ Registro de servicios y gastos generales

✅ Visualización gráfica del dinero disponible

✅ Recomendaciones de ahorro e inversión según edad y experiencia

✅ Diseño responsivo para computadora, tablet y celular

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript Vanilla

## Objetivo

Ayudar a las personas a entender de forma sencilla:

- Cuánto podrían pagar de impuestos
- Cuánto dinero les queda disponible
- Cómo organizar mejor sus gastos
- Opciones básicas para ahorrar e invertir

## Aviso

Esta herramienta tiene fines educativos e informativos..

Los resultados son estimaciones y no constituyen asesoría fiscal, financiera o legal profesional.
